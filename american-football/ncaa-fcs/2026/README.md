# NCAA FCS Football 2026 Calendars

**128 teams, 850 published regular-season games.** Current schedule dates: 2026-08-27 through 2026-11-28.

Times are in **UTC**; your calendar app automatically converts them to your local timezone. Games with a confirmed date but no announced start time are all-day events marked **Start time TBD**. Timed events include the venue's IANA timezone, including neutral sites.

## How to Subscribe

**Google Calendar:** On the desktop website, click **+** next to Other calendars, choose **From URL**, paste the raw URL, and select **Add calendar**. It will also sync to the mobile app.

**Apple Calendar (macOS):** File > New Calendar Subscription > paste the URL > Subscribe.

**Apple Calendar (iOS):** Settings > Calendar > Accounts > Add Account > Other > Add Subscribed Calendar > paste the URL. On newer iOS versions, Calendar settings are under Settings > Apps.

**Microsoft Outlook:** Calendar > Add calendar > Subscribe from web > paste the URL > Import.

Subscribe for schedule changes; importing a downloaded file creates a one-time copy.

## Schedule Updates and Scope

Schedules refresh daily via `scripts/update_ncaa.py`. Your calendar provider controls how quickly subscription changes appear. Event UIDs use ESPN event IDs, so dates and start times can change without creating a new event.

Only published regular-season matchups with identified teams are included. No estimated schedules, unresolved tournament brackets, or postseason games are generated. Season date ranges above describe the currently published games, not an estimated postseason window.

## Data Source

[ESPN NCAA FCS Football schedules](https://www.espn.com/college-football/schedule), using ESPN's public JSON team-schedule API. ESPN is a third-party broadcaster, not the NCAA; it is used here as the existing NFL calendars do. Division membership comes from ESPN's season group hierarchy.
